## 🚫 IMPORTANT - DE REȚINUT

### ⚠️ NOTIFICĂRI TECH-STYLE

**NEW in v2025-12-10.3**
- Centered on screen (not top-right)
- Animated entrance (scale + rotate effect)
- Glowing green border (#2da44e)
- Pulsing bar animation
- Minimum 1.5 seconds display
- Smooth fade-out after

**Fără CSS Libraries**
- Pure CSS animations (no jQuery, no Bootstrap)
- Works in all modern browsers (Chrome, Firefox, Edge, Safari)

### ⚠️ CARD DETECTION

**Smart Buffer Logic**
- Differentiates human typing vs USB reader input
- Timeout between characters: 100ms
- Card reader types much faster than human (10-50ms total)
- Human typing: 500ms+ between chars

**Alphanumeric Support**
- Not just digits (some cards have letters)
- Regex: `/[\dA-Za-z]/`

### ⚠️ VALIDATION ORDER

**Critical: Checks happen in this order**
1. Employee exists (FIRST)
2. Employee active
3. Date validity
4. Holiday check
5. Access levels
6. Door in levels (LAST - most specific)
7. Time evaluation (LAST - current state)

**Why Order Matters**: Return first failing reason (most general → most specific)

### ⚠️ TIME EVALUATION

**days_mask is Binary**
- Each bit = one day of week
- Bit 0 = Monday (1 = 0b0000001)
- Bit 6 = Sunday (64 = 0b1000000)
- Default: 127 = all days (0b1111111)

**Time Check is Inclusive**
- start_time ≤ current_time ≤ end_time
- 08:00:00 is INCLUDED (not < 08:00)
- 18:00:00 is INCLUDED (not < 18:00)

## 📞 DEBUGGING QUICK REFERENCE

### "RESPINS" cu reason "no_employee_for_card"
→ Card nu exista in Employee.card_number, Employee.secondary_card_number, sau EmployeeCard.card_number

### "RESPINS" cu reason "employee_inactive"
→ Employee.active = False (admin trebuie sa marchez True)

### "RESPINS" cu reason "outside_time_segments"
→ Ora curenta nu-i in nici un TimeSegment al AccessLevel-ului, SAU ziua nu-i in days_mask

### "RESPINS" cu reason "door_not_in_access_levels"
→ Usa selectata nu-i in AccessLevel-ul angajatului

### "RESPINS" cu reason "no_access_levels"
→ Employee nu are nici un AccessLevel asignat

### Animatia nu se arata
→ Check browser console (F12) pentru JS errors
→ Verify CSS <style> block loaded
→ Check Network tab: /agent/api/test-read-card returns 200

### Physical reader nu se detecteaza
→ Test in Notepad: trebuie sa vad cifre + Enter
→ Browser trebuie sa fie active (nu in background)
→ Cititorul trebuie in mod "Keyboard Emulation"
→ Check browser console: "Physical card detected: ..." log
